# Metro Blitz — Credits & Attributions

## Game Concept & Development
- **Project:** Metro Blitz
- **Package:** `com.buildstack.metroblitz`
- **Engine/Stack:** Android, Kotlin, Jetpack Compose, SceneView (Google Filament)

## 3D Assets
- All 3D models (characters, obstacles, tracks, props, collectibles) created procedurally using Blender Python scripts via Blender MCP.
- Style: Cartoon low-poly, flat-color palette.
